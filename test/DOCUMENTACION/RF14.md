## RF-14: Recuperar contraseña — Backend (Jest) y Frontend (Vitest)

| | |
|---|---|
| **Requerimiento** | RF-14 · Recuperación de contraseña |
| **Alcance de este documento** | Solicitud de código, verificación y cambio de contraseña |
| **Archivos de prueba** | `test/backend/rf14/recuperar-contrasena.test.js`; `test/frontend/RecuperarContrasena.test.jsx` |

## 1. Resumen

Se verificó el flujo de recuperación de extremo a extremo desde las rutas del backend y las pantallas web: solicitud del código, verificación, emisión del token de recuperación y actualización de la contraseña.

| Capa | Escenarios | Pruebas | Aprobadas |
|---|---|:---:|:---:|
| Backend | Correo, código, expiración, token y contraseña | 5 | 5 |
| Frontend | Correo inválido, flujo completo y error de código | 3 | 3 |
| **Total** | | **8** | **8** |

## 2. Requerimiento verificado

El usuario puede solicitar un código por correo, verificarlo y establecer una contraseña nueva usando un token de recuperación vigente. El código se almacena como hash y tiene vencimiento.

### Código bajo prueba

| Archivo | Elementos |
|---|---|
| `Backend/src/routes/authRoutes.js` | Endpoints de solicitud, verificación y cambio de contraseña |
| `Backend/src/service/MailService.js` | Envío del código de recuperación |
| `Frontend/src/pages/OlvidarContrasena.jsx` | Solicitud del código |
| `Frontend/src/pages/VerificacionCorreo.jsx` | Captura y verificación del código |
| `Frontend/src/pages/IngresoNuevaContrasena.jsx` | Cambio de contraseña |
| `Frontend/src/services/api.js` | Funciones del flujo de recuperación |

## 3. Entorno y estrategia

| Elemento | Detalle |
|---|---|
| Backend | Jest y Supertest; base de datos y servicio de correo simulados |
| Seguridad | JWT firmado y validación de hash mediante bcrypt |
| Frontend | Vitest, jsdom y React Testing Library |
| Servicios del navegador | Funciones API simuladas |

El backend verifica el comportamiento de tokens, hashes y expiración. El frontend simula respuestas de los endpoints y recorre las pantallas usando un router en memoria.

```powershell

```

Desde `Frontend/`:

```powershell
npm test -- --run ../test/frontend/RecuperarContrasena.test.jsx
```

Resultado de la última ejecución: **8 pruebas aprobadas**.

## 7. Observaciones y limitaciones

1. No se envían correos reales; el servicio de correo está simulado.
2. La base de datos está simulada; no se comprueba la persistencia contra un servidor PostgreSQL.
3. La prueba web valida integración de pantallas y manejo de respuestas simuladas, no la entrega del correo ni la disponibilidad del backend.
