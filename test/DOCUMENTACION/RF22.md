# AhorrApp · Documentación de pruebas

## RF-22: Consistencia de información entre plataformas — Backend (Jest) y Frontend (Vitest)

| | |
|---|---|
| **Requerimiento** | RF-22 · Consistencia de información entre plataformas |
| **Alcance de este documento** | Persistencia/consulta autenticada en API y visualización del historial web |
| **Archivos de prueba** | `test/backend/rf22/consistencia-plataformas.test.js`; `test/frontend/Mismovimientos.test.jsx` |
| **Resultado global** | **2 de 2 casos aprobados** |

---

## 1. Resumen

Se comprobó que la API guarda un movimiento asociado al usuario autenticado y permite consultarlo en su listado. En la interfaz web se verifica que los movimientos recibidos se muestran y ordenan por fecha descendente.

| Capa | Escenarios | Pruebas | Aprobadas |
|---|---|:---:|:---:|
| Backend | Crear y consultar movimiento del mismo usuario | 1 | 1 |
| Frontend | Listado y orden por fecha | 1 | 1 |
| **Total** | | **2** | **2** |

## 2. Requerimiento verificado

Las pruebas verifican el uso de una identidad autenticada común para asociar y consultar movimientos, además de su presentación cronológica en web.

### Código bajo prueba

| Archivo | Elementos |
|---|---|
| `Backend/src/routes/movimientosRoutes.js` | Rutas de movimientos |
| `Backend/src/controllers/movimientosController.js` | Creación y consulta de movimientos |
| `Frontend/src/components/Mismovimientos.jsx` | Carga y ordenamiento del listado |
| `Frontend/src/services/api.js` | Función `getMovimientos` |

| Elemento | Detalle |

## 6. Ejecución y evidencia

Desde `Backend/`:

```powershell
npm test -- --runInBand ../test/backend/rf22/consistencia-plataformas.test.js
```

Desde `Frontend/`:

```powershell
npm test -- --run ../test/frontend/Mismovimientos.test.jsx
```

Resultado de la última ejecución: **2 pruebas aprobadas**.

## 7. Observaciones y limitaciones

1. Estas pruebas no conectan una aplicación móvil real; no demuestran sincronización en tiempo real entre clientes.
2. El almacenamiento y las respuestas del backend están simulados. La consistencia entre despliegues/plataformas requiere pruebas de integración con un backend y base de datos de pruebas, además de pruebas del cliente móvil.
3. El caso web cubre el listado y el orden visual, no la creación de movimientos desde cada tipo de dispositivo.
