# AhorrApp · Documentación de pruebas

## RF-01: Registro de usuarios — Backend (Jest) y Frontend (Vitest)

| | |
|---|---|
| **Requerimiento** | RF-01 · Registro de usuarios |
| **Alcance de este documento** | Pruebas automatizadas del registro en API y pantalla web |
| **Archivos de prueba** | `test/backend/rf01/registro.test.js`; `test/frontend/Login.test.jsx` |
| **Resultado global** | **10 de 10 casos aprobados** |

---

## 1. Resumen

Se verificó el registro de usuario desde la interfaz web y el endpoint de autenticación. La cobertura incluye datos correctos, validación de contraseña, duplicidad de correo, tipos de datos inválidos y errores de persistencia.

| Capa | Escenarios | Pruebas | Aprobadas |
|---|---|:---:|:---:|
| Backend | Creación, duplicidad, validaciones y error de base de datos | 8 | 8 |
| Frontend | Contraseña débil y envío exitoso del formulario | 2 | 2 |
| **Total** | | **10** | **10** |

## 2. Requerimiento verificado

La prueba verifica el registro de una cuenta a partir de nombre, apellido, correo electrónico y contraseña. La contraseña debe almacenarse cifrada y la cuenta recibe el rol inicial `user`.

### Código bajo prueba

| Archivo | Elementos |
|---|---|
| `Backend/src/routes/authRoutes.js` | Endpoint `POST /api/auth/register` |
| `Backend/src/db/connection.js` | Consultas de usuario y asignación del rol |
| `Frontend/src/pages/Login.jsx` | Formulario, validación y envío del registro |
| `Frontend/src/services/api.js` | Función `registerUser` |

## 3. Entorno y estrategia

| Elemento | Detalle |
|---|---|
| Backend | Jest y Supertest; conexión a base de datos simulada |
| Frontend | Vitest, jsdom y React Testing Library |
| Dependencias externas | No se usa un servidor ni una base de datos reales |

La prueba de backend comprueba el hash con `bcrypt.compare` y el rol asociado. En la prueba de interfaz se simula el servicio de registro.

## 6. Ejecución y evidencia

Desde `Backend/`:

```powershell
npm test -- --runInBand ../test/backend/rf01/registro.test.js
```

Desde `Frontend/`:

```powershell
npm test -- --run ../test/frontend/Login.test.jsx
```

Resultado de la última ejecución de ambas suites: **10 pruebas aprobadas**.

## 7. Observaciones y limitaciones

1. La base de datos está simulada; no se valida la persistencia contra PostgreSQL.
2. La prueba web simula la respuesta de `registerUser`; no envía solicitudes a un backend desplegado.
3. La suite comprueba las validaciones implementadas en esta pantalla y endpoint; no reemplaza pruebas de integración.
