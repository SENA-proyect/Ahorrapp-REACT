# AhorrApp · Documentación de pruebas

## RF-08: Gestión de usuarios — Backend (Jest) y Frontend (Vitest)

| | |
|---|---|
| **Requerimiento** | RF-08 · Gestionar usuarios |
| **Alcance de este documento** | Autorización del API y edición desde el panel web |
| **Archivos de prueba** | `test/backend/rf08/gestion-usuarios.test.js`; `test/frontend/PanelUsuarios.test.jsx` |
| **Resultado global** | **5 de 5 casos aprobados** |

---

## 1. Resumen

Se verificó que los usuarios con permisos adecuados puedan consultar y administrar usuarios, y que los roles restringidos no puedan ejecutar acciones administrativas.

| Capa | Escenarios | Pruebas | Aprobadas |
|---|---|:---:|:---:|
| Backend | Permisos, listado y asignación de rol | 4 | 4 |
| Frontend | Listado y edición de datos/rol | 1 | 1 |
| **Total** | | **5** | **5** |

## 2. Requerimiento verificado

El panel permite consultar usuarios y editar sus datos. La asignación de roles está restringida: un administrador puede consultar el listado, mientras que la modificación de rol requiere permisos de superusuario.

### Código bajo prueba

| Archivo | Elementos |
|---|---|
| `Backend/src/routes/authRoutes.js` | Rutas del panel de usuarios y validaciones de rol |
| `Backend/src/db/connection.js` | Consultas de usuarios y roles |
| `Frontend/src/pages/PanelUsuarios.jsx` | Listado, formulario de edición y guardado |
| `Frontend/src/services/api.js` | Función `actualizarRolUsuario` |

## 3. Entorno y estrategia

| Elemento | Detalle |
|---|---|
| Backend | Jest y Supertest; consultas SQL simuladas y tokens JWT firmados |
| Frontend | Vitest, jsdom y React Testing Library |
| Peticiones web | `fetch` y actualización de rol simulados |

Los casos del backend ejercitan rutas con distintos roles. El caso de frontend renderiza el panel con un superusuario y verifica la petición de actualización.

## 6. Ejecución y evidencia

Desde `Backend/`:

```powershell
npm test -- --runInBand ../test/backend/rf08/gestion-usuarios.test.js
```

Desde `Frontend/`:

```powershell
npm test -- --run ../test/frontend/PanelUsuarios.test.jsx
```

Resultado de la última ejecución: **5 pruebas aprobadas**.

## 7. Observaciones y limitaciones

1. Las consultas SQL y solicitudes HTTP están simuladas; no se actualiza una base de datos real.
2. La prueba de interfaz cubre el flujo de edición con el rol superusuario. Las reglas de autorización se verifican en el backend.
3. La autorización del cliente no sustituye la autorización del endpoint; la protección debe mantenerse en el servidor.
