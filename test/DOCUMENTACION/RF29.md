## RF-29: Noticias e indicadores de mercado — Backend (Jest) y Frontend (Vitest)

| | |
|---|---|
| **Requerimiento** | RF-29 · Noticias e indicadores |
| **Alcance de este documento** | API de noticias/TRM y componentes web de consulta |
| **Archivos de prueba** | `test/backend/rf29/noticias-indicadores.test.js`; `test/frontend/Noticias.test.jsx` |

## 1. Resumen

Se verificó la consulta de noticias financieras y de la TRM en el backend, además de la visualización, filtrado, paginación y reintento desde la interfaz web.

| Capa | Escenarios | Pruebas | Aprobadas |
|---|---|:---:|:---:|
| Backend | Noticias, respuesta externa, autenticación e indicador TRM | 4 | 4 |
| Frontend | Listado/filtro/paginación y recuperación ante error | 2 | 2 |
| **Total** | | **6** | **6** |

## 2. Requerimiento verificado

El módulo permite consultar noticias financieras y datos de mercado presentados en la aplicación. La API transforma y filtra la respuesta de noticias y entrega la TRM disponible o un valor de respaldo.

### Código bajo prueba

| Archivo | Elementos |
|---|---|
| `Backend/src/routes/noticiasRoutes.js` | Consulta de noticias |
| `Backend/src/routes/alphaVantageRoutes.js` | Ruta de indicador USD/COP |
| `Frontend/src/pages/Noticias.jsx` | Carga, categorías, paginación y error/reintento |

## 3. Entorno y estrategia

| Elemento | Detalle |
|---|---|

| Frontend | Vitest, jsdom y React Testing Library |
| Respuestas web | `fetch` y respuestas de API simulados |

## 7. Observaciones y limitaciones

1. No se contactan NewsAPI, Finnhub ni otros proveedores reales; la respuesta se simula.
2. La TRM de respaldo se verifica como comportamiento actual del endpoint, no como una cotización en tiempo real.
3. La prueba web verifica las solicitudes y estados presentados a partir de datos simulados, no la disponibilidad de los servicios externos.
