# API — Asistente de IA (`aiController`)

**Base path:** `/api/ai`
**Archivo de rutas:** `src/routes/aiRoutes.js`
**Archivo de controlador:** `src/controllers/aiController.js`

> ⚠️ **Sin autenticación:** a diferencia de todos los demás módulos, este router **no** tiene `verifyToken` aplicado. `POST /api/ai/chat` es accesible sin token. Si esto no es intencional, hay que agregar el middleware en `aiRoutes.js`.

Este controlador es un simple proxy hacia OpenRouter (`https://openrouter.ai/api/v1/chat/completions`), usando el modelo definido en `process.env.MODEL` (por defecto `google/gemini-3.1-flash-lite`) y la key en `process.env.OPENROUTER_API_KEY`.

---

## 1. Chat con el asistente

`POST /api/ai/chat`

### Body
```json
{
  "system": "Eres un asesor financiero personal para la app AhorrApp",
  "messages": [
    { "role": "user", "content": "¿Cómo voy con mis gastos este mes?" }
  ]
}
```
> `messages` es obligatorio: un array en formato estándar de chat (`{ role, content }`, roles `"user"`/`"assistant"`). `system` es opcional — si se omite, se usa `"Asistente de AhorrApp"` por defecto. El backend antepone el mensaje de sistema y reenvía todo el array tal cual a OpenRouter, con `max_tokens: 800`.

### Respuesta 200
```json
{ "reply": "Vas bien: llevas $100.000 de gastos sobre un presupuesto de $400.000 este mes (25%)." }
```

### Respuesta 500 — OpenRouter no devolvió una respuesta usable
```json
{ "error": "OpenRouter no devolvió una respuesta válida" }
```

### Respuesta 500 — error de OpenRouter o de conexión
```json
{ "error": "<mensaje de error devuelto por OpenRouter, o 'Error de conexión'>" }
```

> Nota: si `messages` no viene en el body (o no es un array), `...messages` lanza un `TypeError` al construir la petición — pero como esto ocurre dentro del mismo `try`, sí cae en el `catch` genérico. Como no es un error de axios, `err.response` es `undefined`, así que la respuesta termina siendo `{ "error": "Error de conexión" }` con status 500 (un mensaje engañoso para lo que en realidad es un body mal formado). Envía siempre `messages` como array, aunque sea vacío.
