# RF-16 · Cerrar sesión

## Propósito

Comprobar que cerrar sesión borre las credenciales guardadas, redirija al inicio de sesión y evite el acceso a rutas protegidas cuando la sesión no sea válida.

## Archivo

- [`rf16.test.jsx`](rf16.test.jsx) prueba el flujo del contexto de autenticación y `ProtectedRoute` con Jest y React Testing Library en jsdom. Usa `MemoryRouter` para simular la navegación sin abrir un navegador.

## Entorno y estrategia

| Elemento | Detalle |
|---|---|
| Framework | Jest con entorno `jsdom` |
| Interacción | React Testing Library y `user-event` |
| Navegación | `MemoryRouter` y `ProtectedRoute` reales |
| Almacenamiento | `localStorage` y `sessionStorage` de jsdom |

La prueba renderiza el proveedor real de autenticación junto con una ruta privada mínima. No se conecta a servidor ni requiere una sesión externa.

## Casos de prueba y resultados

La ejecución registrada pasó **cuatro de cuatro pruebas**. El tercer caso es parametrizado y genera una prueba para cada evento.

Antes de cada caso, limpia `localStorage` y `sessionStorage` y luego agrega un perfil, un usuario anterior, un token de prueba y una preferencia visual.

| Caso | Acción | Comprobaciones |
|---|---|---|
| Cierre de sesión | Pulsa el botón en una ruta privada | Se navega al inicio de sesión, se eliminan `user`, `usuario` y `token` de ambos almacenamientos y se conserva `preferencia` |
| Ruta privada sin token | Retira el token antes de abrir la ruta | Se presenta la pantalla de inicio de sesión |
| Revalidación por evento | Retira el token y dispara `storage` o `pageshow` | La sesión se revalida y se muestra el inicio de sesión en ambos escenarios |

## Trazabilidad con el requerimiento

| Comportamiento de RF-16 | Evidencia automatizada |
|---|---|
| Cerrar sesión y limpiar credenciales | Comprueba que desaparezcan las claves de usuario y token de `localStorage` y `sessionStorage` |
| Conservar datos ajenos a la sesión | Comprueba que la preferencia visual siga almacenada |
| Restringir una ruta privada | Verifica redirección cuando falta el token |
| Detectar cambios de sesión mientras la app está abierta | Prueba los eventos `storage` y `pageshow` |

## Ejecutar

Desde la raíz del repositorio, con las dependencias instaladas:

```powershell
npm test --prefix Frontend -- rf16
```

RF-16 solo tiene pruebas web en esta carpeta. No hay un archivo de prueba de API para este requisito. La ejecución registrada aprobó **cuatro de cuatro pruebas**.

## Alcance

La suite verifica la limpieza y navegación en el cliente dentro de un entorno simulado. No comprueba revocación de token en el servidor ni el comportamiento de un navegador real. La matriz de cumplimiento de la rama de Juan menciona también el almacenamiento seguro y el PIN del cliente móvil, pero esos flujos no están cubiertos por esta prueba Jest web.
